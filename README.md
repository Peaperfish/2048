# 2048

A clone of the puzzle game [2048](https://en.wikipedia.org/wiki/2048_(video_game)), made in Unity 6 with C#. **Work in progress.**

## Status

- **Done:** the 4 × 4 board, tile states (number and colour), and spawning new tiles in random empty cells (`TileBoard`, `TileGrid`, `TileRow`, `TileCell`, `Tile`, `TileState` in `Assets/Scripts`).
- **Next:** sliding and merging tiles with the arrow keys, the score, and game over.

## Running it

1. Open this folder in Unity **6000.0.45f1** (or a newer Unity 6).
2. Open `Assets/Scenes/2048.unity`.
3. Press **Play**.

Tiles use the Clear Sans font, included in `Assets/Fonts`.
